지정한 챕터에 새 SQLD 문제를 추가한다.

사용법: /add-question [챕터ID]
예시: /add-question part2_ch1

실행 절차:
1. `data/questions/[챕터ID].json` 파일을 읽는다.
2. 현재 마지막 id의 번호를 파악해 다음 id를 계산한다 (예: p2c1_042).
3. 사용자에게 다음 정보를 순서대로 요청한다:
   - 문제 본문 (마크다운 가능, SQL 코드 블록 포함 가능)
   - 보기 1~4번
   - 정답 번호 (1~4)
   - 해설
   - 태그 (쉼표 구분, 선택)
4. 입력받은 내용으로 Question 객체를 생성해 JSON 배열 끝에 추가한다.
5. /validate-data 를 실행해 추가된 문항 검증 후 완료 메시지를 출력한다.

챕터ID를 지정하지 않으면 사용 가능한 챕터 목록을 보여주고 선택을 요청한다.
