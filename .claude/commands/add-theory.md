지정한 챕터의 이론 마크다운 파일에 새 섹션을 추가하거나 내용을 보완한다.

사용법: /add-theory [챕터ID]
예시: /add-theory part2_ch1

실행 절차:
1. `data/theory/[챕터ID].md` 파일을 읽어 현재 목차(## 헤딩 목록)를 출력한다.
2. 사용자에게 추가할 섹션 제목을 입력받는다.
3. 섹션 내용을 마크다운으로 작성한다:
   - 개념 설명
   - SQL 예제 코드 블록 (```sql ... ```)
   - 핵심 포인트 요약 (> 인용 블록 또는 목록)
4. 파일 끝 또는 지정 위치에 섹션을 추가한다.
5. 추가된 내용을 미리보기로 출력한다.

챕터ID 없이 실행하면 사용 가능한 챕터 목록을 보여준다:
- part1_ch1: 1과목 1장 — 데이터 모델링의 이해
- part1_ch2: 1과목 2장 — 데이터 모델과 SQL
- part2_ch1: 2과목 1장 — SQL 기본
- part2_ch2: 2과목 2장 — SQL 활용
- part2_ch3: 2과목 3장 — 관리 구문
