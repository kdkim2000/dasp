현재 개발 과정의 관찰·결정·문제·교훈을 docs/journal/JOURNAL.md 에 새 항목으로 추가한다.

## 사용법
```
/log [관찰 내용]
/log "Foundation Builder의 localStorage SSR 가드가 예상보다 까다로웠다"
/log  ← 인수 없이 실행하면 대화형으로 항목 수집
```

## 실행 절차

1. docs/journal/JOURNAL.md 를 읽어 현재 마지막 Phase 번호와 최근 에이전트 컨텍스트를 파악한다.

2. 사용자가 인수를 전달했다면 그 내용을 핵심 관찰로 사용한다.
   인수가 없으면 다음을 차례로 질문한다:
   - "무엇을 했나요? (작업 내용)"
   - "어떤 결정을 내렸나요? (없으면 Enter)"
   - "어떤 문제가 있었나요? (없으면 Enter)"
   - "이 경험의 교훈은? (핵심 한 줄)"
   - "현재 바이브는? (⚡고에너지/😌안정적/🤔복잡/🎉완성/😤막힘)"

3. 현재 시각(Get-Date 또는 date)과 컨텍스트를 포함한 항목을 생성한다:
   ```
   ### [현재날짜 현재시각] [Phase N] [현재 에이전트/작업] — 핵심 한 줄 요약

   **작업**: ...
   **결정**: ...  (있을 때만)
   **장애물**: ... (있을 때만)
   **해결**: ...  (있을 때만)
   **교훈**: ...
   **바이브**: ...
   ```

4. docs/journal/JOURNAL.md 의 `---` 구분선 아래, 기존 마지막 항목 다음에 추가한다.

5. 추가 완료 후 "저널 항목 추가됨 ✓" 확인 메시지를 출력한다.
