docs/AGENTS.md 에 정의된 특정 에이전트 역할로 작업을 시작한다.

사용법: /run-agent [에이전트번호]
예시: /run-agent 3   → Foundation Builder 역할로 작업 시작

실행 절차:
1. docs/AGENTS.md 를 읽어 해당 번호 에이전트의 정의를 로드한다.
2. 에이전트의 소유 파일 목록을 확인하고, 선행 조건(의존 파일)이 존재하는지 점검한다.
3. 선행 조건 미충족 시: 누락된 파일 목록과 먼저 실행해야 할 에이전트를 안내한다.
4. 선행 조건 충족 시: 에이전트 역할을 선언하고 소유 파일 작업을 시작한다.
   - "Agent [번호] — [이름] 역할로 작업을 시작합니다."
   - 소유 파일 외 다른 파일은 수정하지 않는다.
5. 작업 완료 후 검증 기준을 실행하고 결과를 보고한다.

에이전트 번호 없이 실행하면 전체 에이전트 목록과 현재 완료 상태를 표로 출력한다.
