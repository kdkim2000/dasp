data/questions/*.json 파일 전체를 읽어 스키마 유효성을 검사한다.

검사 항목:
- id 형식: `p{1|2}c{1|2|3}_{3자리숫자}` (예: p2c1_001)
- part: 1 또는 2
- chapter: id의 과목·챕터와 일치
- options: 정확히 4개의 문자열 배열
- answer: 0~3 범위의 정수
- content, explanation: 비어있지 않은 문자열
- 같은 파일 내 id 중복 없음
- 파일 간 전체 id 중복 없음

결과를 파일별로 표로 출력한다:
| 파일명 | 문항 수 | 오류 수 | 오류 내용 |

오류가 있으면 해당 문항 id와 수정 방법을 제시한다.
오류가 없으면 "데이터 검증 통과 ✓ — 총 N문항" 을 출력한다.
