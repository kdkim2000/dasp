# PRD — SQLD 시험 준비 사이트

## 개요

SQLD(SQL Developer) 자격증 시험을 준비하는 학습자를 위한 이론 학습 및 예상문제 풀이 웹 사이트.

- **목표 사용자**: SQLD 시험 준비생 (입문~중급 SQL 학습자)
- **핵심 가치**: 시험 범위에 맞춘 체계적 이론 정리 + 반복 문제 풀이를 통한 합격 준비

---

## 시험 구조

SQLD는 2과목으로 구성되며, 과목별 40% 이상 + 전체 60점(100점 만점) 이상 합격.

| 과목 | 제목 | 문항 수 | 배점 |
|------|------|---------|------|
| 1과목 | 데이터 모델링의 이해 | 10문항 | 20점 |
| 2과목 | SQL 기본 및 활용 | 40문항 | 80점 |

### 1과목 세부 구성
- 1장: 데이터 모델링의 이해 (데이터 모델 개념, 모델링 특징, ERD)
- 2장: 데이터 모델과 SQL (정규화, 관계, 식별자)

### 2과목 세부 구성
- 1장: SQL 기본 (SELECT, DML, DDL, DCL, TCL, 함수, GROUP BY, JOIN)
- 2장: SQL 활용 (서브쿼리, 집합 연산자, 계층 쿼리, 윈도우 함수)
- 3장: 관리 구문 (DML, DDL, DCL)

---

## 핵심 기능

### 1. 이론 학습
- 과목/챕터별 이론 콘텐츠 제공 (텍스트 + 코드 예제)
- 핵심 개념 요약 카드
- SQL 예제 코드 하이라이팅

### 2. 문제 풀이

**학습 풀 (100문항)**
- **단원별 풀이**: 특정 챕터 문제만 선택해서 풀기 (진도별 학습용)
  - 1과목: 35문항 (1장 20 + 2장 15)
  - 2과목: 65문항 (1장 30 + 2장 25 + 3장 10)

**평가 및 부가 기능**
- **전체 모의고사**: 실제 시험과 동일한 50문항 구성 (1과목 10 + 2과목 40), 제한 시간 90분
- **오답 재풀이**: 틀린 문제만 모아서 재시도
- **북마크 풀이**: 북마크한 문제만 모아서 풀기

### 3. 문제 형식
- 4지선다 객관식
- 문제 + 보기 + 해설 (정답 제출 후 공개)
- SQL 코드 블록 포함 문제 지원

### 4. 학습 진도 관리 (localStorage 기반)
- 문제별 정답/오답 기록
- 과목/챕터별 정답률 통계
- 북마크(오답 노트 대용)
- 마지막 학습 위치 기억

### 5. 대시보드
- 전체 진도율 (풀이 완료 문제 수 / 전체 문제 수)
- 과목별 정답률 차트
- 최근 오답 목록
- 취약 챕터 하이라이트

## UI 구성

```
/                    → 대시보드 (진도율, 최근 오답, 바로가기)
/theory              → 이론 목차
/theory/[chapterId]  → 챕터별 이론 본문
/quiz                → 문제풀이 메뉴 (단원별 / 모의고사 / 오답 / 북마크)
/quiz/chapter/[id]   → 단원별 문제풀이
/quiz/exam           → 전체 모의고사
/quiz/wrong          → 오답 재풀이
/quiz/bookmarks      → 북마크 문제
```
