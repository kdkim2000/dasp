# 08. 정답 위치/길이 편향 해소, 오답 품질 향상, 이론-문제 커버리지 보강

**작성일**: 2026-09-07
**상태**: 완료

---

## 주요 문제점 (개선 전 실측)

| 문제 | 내용 |
|------|------|
| 정답 위치 편향 | 챕터 문제은행 전체 54.0%가 2번(index1) 정답, 1번은 3.3%. 모의고사도 53~58% vs 4%. 여러 파일에서 1번(또는 3번) 정답이 0% |
| 정답 길이 편향 | 정답이 4개 중 최장 옵션인 비율 챕터 59.4%, 모의고사 55%(기대값 25%). 정답 평균 길이가 오답의 약 1.7~2배 |
| 오답 품질 | "소스코드/예산/하드웨어" 등 무관 도메인 필러, "임의로/자율적/자유롭게" 상식형 오답, "동일함/차이없음" 보일러플레이트가 반복 사용됨 |
| 이론-문제 커버리지 갭 | 14개 챕터 전체에서 "N가지" 열거형 항목 중 1~2개만 출제, 이론 후반 심화 섹션 통째 미출제 |
| 검증 스크립트 버그 | `scripts/validate-questions.ts`가 UTF-8 BOM 때문에 8개 파일에서 파싱 실패, 사실상 무검증 상태였음 |

---

## 목표 스펙

- 파일별 정답 위치(1~4번) 분포 20~30% 이내(라운드로빈 `target=(i+offset)%4`로 배정, 파일마다 offset을 0~3 순환)
- 정답=최장옵션(단독) 비율 20~35%
- 정답/오답 평균 길이 비율 0.85~1.15
- explanation 50자 이상 (검증기 기존 기준)
- 오답은 같은 챕터/주제의 실제 DAsP 전문용어만 사용, 무관 도메인 필러·상식형 오답·보일러플레이트 금지
