# 09. Part1(전사아키텍처 이해) 문제 난이도 실전화

**작성일**: 2026-09-20
**상태**: 완료

---

## 배경

실제 DAsP 시험 응시 경험을 바탕으로, 기존 `part1_ch1~3.json`의 문제(총 75문항)가
단답형 암기 문제 위주(하~중 난이도, 짧은 지문·보기)로 실제 시험과 괴리가 크다는
피드백을 받음. 실제 시험은 지문이 길고 "가장 옳은/옳지 않은 것은?" 형태로 4개 보기
모두 그럴듯하게 구성되어 정확한 개념 이해 없이는 풀 수 없는 난이도임.

part별로 순차 진행하는 개선 작업 중 1과목(전사아키텍처 이해) 3개 챕터를 우선 처리.

---

## 처리 내용

- `data/questions/part1_ch1.json` (29문항), `part1_ch2.json` (21문항),
  `part1_ch3.json` (25문항) 전량 재작성 (기존 문항 전체 삭제 후 신규 작성)
- 모든 문항을 각 챕터 이론 파일(`data/theory/part1_ch{1,2,3}.md`) 내용에 근거해 작성
- mockexam(exam1/exam2)은 별도 문항을 보유하므로 이번 작업 범위에서 제외

## 적용한 난이도/스타일 기준

- 질문 형식: "다음 중 ~에 대한 설명으로 가장 옳은/옳지 않은 것은?" 형태로 통일
- 보기: 4개 모두 완결된 문장, 정답 외 오답도 이론에 실제 등장하는 개념을 범위 오류·
  주체 바뀜·조건 누락·정반대 서술 등으로 비틀어 구성 (단순 단어 오답 지양)
- explanation: 정답 근거뿐 아니라 주요 오답이 왜 틀렸는지 함께 명시
- 난이도 분포(실제 배정치): ch1 상 19/중 9/하 1, ch2 상 13/중 6/하 2, ch3 상 15/중 8/하 2
  → 전체 75문항 중 상 47(63%) / 중 23(31%) / 하 5(6%)로 기존 대비 상 비중 대폭 확대
