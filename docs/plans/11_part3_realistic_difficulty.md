## 배경

part1, part2에 이어 3과목(데이터 표준화) 3개 챕터를 동일 기준으로 개선. `docs/contents/03-*.md`
강의 원본과 `data/theory/part3_ch{1-3}.md`에 이미 반영된 심화 개념(표준 체계 4단계, 도메인
추상화 가치, DA/DBA 역할 정정, RACI A/R 판단, 변경영향도분석 사례 등)을 근거로, 데이터
표준화의 "근본 개념"(왜 표준화가 필요한가, 무엇을 표준화하는가, 어떻게 관리하는가)을
정확히 이해해야 풀리는 긴 지문 기반 문제로 전면 재구성.

## 처리 내용

- `data/questions/part3_ch1.json`(20), `part3_ch2.json`(19), `part3_ch3.json`(21) 전량
  삭제 후 재작성 — 총 60문항
- 모든 문항에 실제 데이터 표준화 실무 시나리오(동음이의어/이음동의어 혼재 사례, 도메인
  변경 파급효과, RACI 책임 판정, 표준 준수 감사, 데이터 품질 지표 계산 등)를 지문으로 제시
- 정의 암기형 문제 배제, 개념을 실제 상황에 적용·판단해야 정답이 나오는 구조로 통일
- 데이터 품질 지표(완전성·정확성·표준준수율) 실제 수치 계산 문제 포함(part3_ch3)

## 적용한 핵심 함정 포인트 (이론의 "단골 오답" 반영)

- DA(전사·전략, What) vs DBA(기술·운영, How) 역할 혼동 함정 다수 반영
- 표준 체계 4단계(단어→용어→도메인→코드) vs 데이터 표준 4대 구성요소(명칭·정의·형식·규칙)
  구분 문제
- 동음이의어(같은 이름·다른 의미) vs 이음동의어(다른 이름·같은 의미) 구분
- 각종 4~6단계 프로세스(표준화 추진, 변경 관리, 폐기, 준수 감사, 신규 등록)의 순서
  뒤바꾸기형 오답
- RACI 매트릭스에서 활동별 A(최종 책임) 주체 판단
