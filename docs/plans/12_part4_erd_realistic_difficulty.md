# 12. Part4(데이터 모델링) 문제 전면 재구성 — ERD 기반 "상" 난이도

**작성일**: 2026-09-20
**상태**: 완료

---

## 배경

사용자가 실제 DAsP 시험에서 가장 크게 체감한 차이 지점이 4과목(데이터 모델링)이었음.
단순 지식 문답이 아니라 **실제 ERD를 제시하고 이를 분석·검증·개선할 수 있는지**를
묻는 문제가 중심이었다는 피드백에 따라, 직전 작업(ERD 렌더링 구조 도입,
`components/quiz/MermaidDiagram.tsx` 등)을 기반으로 4개 챕터 전체를 재작성.

## 처리 내용

- `data/questions/part4_ch1.json`(14), `part4_ch2.json`(16), `part4_ch3.json`(18),
  `part4_ch4.json`(17) 전량 삭제 후 재작성 — 총 65문항, **전 문항 난이도 "상"**
- 전체 문항의 약 60%(40문항)에 `data/theory/part4_ch{1-4}.md` 이론과 정합하는 mermaid
  `erDiagram`을 문제 지문에 직접 포함 — 카디널리티(`||--o{` 등), 식별/비식별 관계
  (실선 `--` vs 점선 `..`), PK/FK 속성 표기까지 실제 표기법 그대로 사용
- 나머지 문항은 ERD 없이도 "상" 난이도를 유지하는 실무 시나리오 적용형으로 구성
  (Zachman 매핑, 하드웨어 성능 지표 진단, 반정규화 절차 등)

## 문제 유형 구성 (요청 반영)

1. **ERD 판독형**: 주어진 ERD의 표기법(카디널리티·식별관계 등)을 정확히 해석해야 답이
   나오는 문제 (예: `p4c1_001`, `p4c1_003`, `p4c1_008`)
2. **정규화 결함 진단형**: 정규화가 덜 된 ERD(부분/이행 함수 종속, 다가 종속이 남아있는
   엔터티)를 제시하고 어떤 정규형을 위반했는지, 어떻게 분해해야 하는지 묻는 문제
   (`p4c1_010`, `p4c3_009`~`p4c3_011` — 2NF/3NF/4NF 위반 사례를 단계적으로 구성)
3. **모델링 역량 적용형**: 슈퍼타입/서브타입 전략 선택, 참조 무결성 규칙 선택, 반정규화
   기법 판별, M:N 해소 절차 등 실제 설계 의사결정을 묻는 문제
- 모든 보기(선택지)는 완전히 무관한 오답이 아니라, 정답과 유사하지만 핵심 조건(방향이
  뒤바뀜, 단계 누락, 개념 혼동 등)에서만 틀리도록 설계 — 소거법이 아닌 정확한 이해를
  요구
