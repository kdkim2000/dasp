# 13. Part1~4 오답 정밀도 개선 + 정답 위치 편중 해소

**작성일**: 2026-09-20
**상태**: 완료

---

## 배경

Part1~4 재작성 이후 사용자로부터 두 가지 결함 지적:
1. 오답 보기가 정답만큼 정밀하지 않아 "무관하다/불가능하다"류 즉각 기각형 문장으로
   소거법이 통함
2. 정답이 특정 위치(인덱스)에 쏠려 있음

## 진단

전량 스캔 결과 part2·part3·part4(총 208문항)는 **예외 없이 정답이 0번**이었고,
part1도 62~68%까지 특정 인덱스(2번 또는 3번)에 쏠려 있었음. 대조군인 기존
모의고사(exam1/exam2, 100문항, 이번 작업 미대상)는 24~26%로 고르게 분포되어
있어 이번 재작성 과정에서 발생한 회귀임을 확인.

## 처리 내용

- Part별 4개 fork 서브에이전트를 병렬 실행(part1/2/3/4 각 담당), 283문항 전체를
  대상으로 다음을 동시 수행:
  1. 오답 3개를 모두 "근접 오답"으로 재작성 — 정답과 유사한 길이·문체를 유지하되
     역할 반전(DA↔DBA), 규칙 교체(Cascade↔Restrict), 단계 순서 교환, 유사 개념
     혼동(2NF↔3NF, 동음이의어↔이음동의어), 방향 반전, 계산 실수형 근접값 등으로
     "부분적으로만" 틀리게 구성. "무관하다/불가능하다" 류 즉각 기각형 문장 제거
  2. 정답 위치를 파일별로 0~3 인덱스에 고르게 재배치(정답 텍스트 자체는 불변,
     배열 내 위치와 `answer` 값만 변경)
  3. `explanation`을 새 옵션 순서에 맞게 재작성하고, 각 오답이 어떤 개념과
     혼동시키는지 구체적으로 명시
- `id`, `content`(지문/ERD 원문), `part`, `chapter`, `tags`, `difficulty`,
  `questionType`은 전량 보존

## 검증 결과

- 중복 옵션 텍스트, 정답 인덱스 유효성 등 구조적 결함 0건 (전용 점검 스크립트)
- `npx tsx scripts/validate-questions.ts` → 16개 파일 383문항, 고유 ID 검증 통과
- `npm run type-check`, `npm run test`(13개), `npm run build`(SSG) 모두 통과
- 4개 파일에서 임의 샘플 문항을 직접 출력해 오답 정밀도·explanation 정합성 육안 확인
  — 모두 "그럴듯하지만 특정 지점에서만 틀림" 수준으로 개선됨을 확인
