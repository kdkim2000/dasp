# 14. 모의고사(exam1/exam2) 전면 재작성

**작성일**: 2026-09-20
**상태**: 완료

---

## 배경

Part1~4 챕터 문제은행은 실전형(긴 시나리오 지문·근접 오답·균등 정답 위치, part4는
ERD 기반)으로 전면 재작성되었으나, 최종 모의고사(`exam1.json`, `exam2.json`, 각 50문항)는
손대지 않아 옛 방식(단답형 정의 매칭, part4에 ERD 전무)이 그대로 남아있었음. 동일 기준을
모의고사에도 적용해달라는 요청에 따라 전량 재작성.

## 처리 내용

- `data/questions/mockexam/exam1.json`, `exam2.json` 전량 재작성 (각 50문항, part별
  10/10/10/20 구성 유지, id 형식 `examN_NNN` 유지) — exam1·exam2를 담당하는 fork
  2개를 병렬 실행
- 1~3과목은 part1~3과 동일한 시나리오 기반 문제로, 4과목(각 20문항, 총 40문항)은
  mermaid `erDiagram` 또는 SQL DDL을 지문에 포함해 카디널리티 판독·정규화 결함
  진단·식별관계 판별·서브타입 변환 전략·참조무결성 규칙 선택 등 실제 모델링 역량을
  검증하는 문제로 구성
- exam1은 EA 개요/프레임워크·정보요구 조사·데이터표준 수립·개념/논리모델링 기초에,
  exam2는 EA 구축/거버넌스·정보요구 분석/검증·데이터표준 관리·논리모델링 심화/물리
  모델링에 비중을 두어 두 회차를 차별화

## 이슈 및 조치: exam1 정답 위치 편중 (fork의 세션 한도 초과로 인한 미완성)

exam1을 작성한 fork가 문항 작성은 완료했으나(내용 품질은 우수, 50문항·part별 개수
정확, ERD 12/20 포함) API 세션 한도(rate limit)에 걸려 정답 위치 재배치 단계를
마치지 못하고 중단됨 — 결과적으로 41/50문항이 정답 인덱스 0에 몰림. exam2는 정상
완료(분포 13/15/8/14, 26%/30%/16%/28%로 양호).

**조치**: exam1을 다시 통째로 재작성하는 대신, 이미 검증된 문항 내용(지문·정답·오답
텍스트)은 그대로 보존한 채 **정답 위치만 기계적으로 재배치**하는 스크립트를 작성해
적용 — 41문항 중 28문항을 인덱스 0에서 1/2/3으로 이동(옵션 배열의 두 항목을
swap하고 `answer` 값을 갱신), explanation 안의 원문자 번호(①②③④)도 이동된 위치에
맞게 함께 치환하여 설명과 옵션 번호가 어긋나지 않도록 함. 스크립트 적용 후 4개
문항을 직접 대조해 옵션·번호·설명이 모두 정합함을 확인.
